# ArrowLink

O link de rede do fechamento: nome em caixa-alta sublinhado e a seta diagonal.

- `children` é o nome do destino em caixa-alta: SITE, INSTAGRAM, YOUTUBE, LINKEDIN. Sempre abre em nova aba.
- Use só para sair da peça (site, redes, matéria). Para ação dentro da página, não use seta.
- Cor `ink`; no hover a seta sobe 3px e o texto vira `accent`.
- No palco ficam em linha, alinhados à direita. No mobile, em lista com fio entre os itens.

Props: `href`, `children`, `className`, `style`.
