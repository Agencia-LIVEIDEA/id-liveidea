# Logo

O logotipo LIVEIDEA em SVG, herdando a cor do texto (`currentColor`), montado com os vetores originais do deck.

- Defina a cor pelo `color` do pai: `on-laranja` (névoa) sobre laranja e grafite; `laranja` ou `grafite` sobre névoa e cinza.
- `height` em px (padrão 46, a altura do logo na capa de 1920). A largura acompanha.
- Respiro mínimo em volta: a altura do pingo do i.
- Não estique, não contorne, não aplique degradê, não troque a fonte. Para imagem fixa use os arquivos do grupo Logos.

Props: `height`, `title`, `className`, `style`.
