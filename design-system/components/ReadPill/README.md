# ReadPill

A pílula laranja LEIA, que leva do recorte de imprensa para a matéria.

- Texto curto em caixa-alta, uma palavra: LEIA. Com `href` vira link que abre em nova aba; sem `href`, botão com `onClick`.
- Fica no canto superior direito do PressCard, alinhada às aspas.
- O texto névoa sobre laranja dá 2,5:1, como no deck. O sublinhado e o formato de pílula carregam o sinal de link; não use a pílula para ações críticas.
- No hover troca para âmbar com texto grafite (9,0:1).

Props: `children`, `href`, `onClick`, `className`, `style`.
