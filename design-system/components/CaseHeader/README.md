# CaseHeader

O cabeçalho de um case: o cliente em `label`, o nome do projeto em Display e a descrição curta em `body-tight`.

- `client` em caixa-alta, só o nome do grupo ou marca (GRUPO EMS).
- `title` recebe os mesmos filhos do Display, com a regra da mistura.
- `children` é a descrição: duas a quatro linhas, começando por verbo no passado ou por substantivo ("Atuamos no planejamento...", "Transformação de planta fabril...").
- Logo depois vem a grade de Stat do case.

Props: `client`, `title`, `children`, `size` (padrão 120), `className`, `style`.
