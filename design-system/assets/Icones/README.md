# Ícones

Todos no estilo da apresentação comercial: grid de 24px, traço bold de 2,5px, pontas chatas (butt), cantos vivos (miter), sem preenchimento. Os arquivos estão em grafite (#121212). Para outra cor, use o componente Icon, que herda a cor do texto.

**Conjunto (`icone-*.svg`)**
- Navegação: `seta-direita`, `seta-esquerda`, `seta-diagonal` (link que sai da peça), `chevron-direita`, `chevron-esquerda`, `chevron-baixo`.
- Ações: `mais`, `fechar`, `check`, `menu`, `play`, `busca`, `link-externo`, `download`.
- Informação de evento e proposta: `local`, `calendario`, `relogio`, `pessoas`, `email`, `camera`, `musica`, `microfone`, `talheres`, `hospedagem`, `carro`, `aviao`.

**Do deck original**
- `seta.svg` e `seta-diagonal.svg`: a seta fina dos links de redes no fechamento da apresentação comercial, mantida como está no deck.
- `aspas.svg`: aspas de abertura dos cartões de imprensa.

Sempre ao lado de um rótulo, alinhado à primeira linha do texto, com vão de 10px. Tamanhos de 16, 24, 32 ou 48px.
